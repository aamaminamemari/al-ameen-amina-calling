নতুন স্কুলের জন্য চালু করার ধাপ:
------------------------------------------------------------
১. নতুন অ্যাকাউন্ট তৈরি করুন (বিনামূল্যে):
   - Neon.tech (PostgreSQL ডাটাবেস) -> DATABASE_URL কপি করুন
   - Cloudinary.com (MP3 রেকর্ডিংয়ের জন্য) -> Cloud Name, API Key, Secret কপি করুন

২. নতুন স্কুলের পিসিতে ইনস্টল করুন:
   - "School_Calling_System" ফোল্ডারটি পেন ড্রাইভে নিয়ে নতুন পিসিতে রাখুন।
   - "INSTALL_AND_START.bat" ডাবল-ক্লিক করুন।
   - প্রথমবার চালু হলে ".env" ফাইলটি নোটপ্যাডে খুলবে — সেখানে নতুন স্কুলের
     DATABASE_URL, CLOUDINARY_*, SCHOOL_NAME এবং Gateway IP বসিয়ে Save করুন।

৩. প্রথম Super Admin আইডি তৈরি করুন:
   - CMD খুলে চালান:
     cd C:\School_Calling_Server
     node create-admin.js ADMIN001 Admin@123 "Principal"

৪. ওয়েব প্যানেল ব্যবহার করুন:
   - ব্রাউজারে http://localhost:3000 খুলুন (অথবা Render-এ হোস্ট করুন)।
   - Students & Contacts ট্যাব থেকে Excel (.xlsx) ইমপোর্ট করুন,
     Calling Schedule সেট করুন এবং Call Logs / MP3 Recordings শুনুন!
